# Banking Data Analysis

## Project Overview

This project analyzes banking data to evaluate loan portfolio performance and debit and credit transaction patterns. Using Microsoft Excel, MySQL, Power BI, and Tableau, the project focuses on data preparation, KPI calculation, exploratory analysis, and dashboard development to support data-driven decision-making.

## Project Objectives

- Analyze loan portfolio performance and key loan KPIs.
- Examine debit and credit transaction activity.
- Identify patterns and trends in banking data.
- Use SQL queries to calculate and analyze key indicators.
- Create interactive dashboards to visualize banking metrics.
- Present findings through data visualizations and a project presentation.

## Tools and Technologies

- **Microsoft Excel:** Data cleaning, analysis, calculations, and dashboard creation.
- **MySQL:** Database management, data preparation, and analytical SQL queries.
- **Microsoft Power BI:** Interactive dashboards and visual analytics.
- **Tableau:** Data visualization and dashboard development.
